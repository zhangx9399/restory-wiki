## How Cleaning Works in ReStory

The official Steam description establishes the broad repair loop: take a gadget apart, clean it, replace faulty parts, and assemble it again. It also describes an in-depth cleaning and restoration system. This confirms that cleaning components belongs in a normal repair, but the store page does not document a permanent button label, keyboard key, or every workbench gesture.

In practice, cleaning is applied to a part that has been removed from the device and placed into the appropriate work area. It is not an automatic whole-device action that works from any point on the bench. Treat selection, placement, and interaction state as separate checks: a part can look close to a station without actually being accepted by that station.

The Steam store supports the overall sequence. A Steam Community reply supplies the cup-location clue, while the same thread includes reports of sound playing without visible progress. Those reports suggest useful checks; they do not prove one cause.

## Cleaning the First Pokia Device

Expose and select the visibly dirty component rather than moving the complete Pokia device or a nearby clean piece. Disassembly gives the cleaning interaction a specific component. If several loose pieces are on the bench, confirm which one still shows dirt.

Move that component toward the cup or cleaning spot on the upper-right of the workbench. This location comes from a player reply in the “Stuck at First Item” discussion, not an official control reference. Look for the interface to accept the component or open a cleaning interaction; resting it nearby may not establish that state.

Once the interaction is active, use its scrubbing action and watch the dirty surface for visual progress. Sound alone is weak evidence: players in the cited thread heard cleaning audio while dirt remained. If the surface does not change, check placement, selection, input, and session state.

## Using the Correct Workbench Area

The workbench stages have different purposes. Disassembly exposes components. The cleaning area accepts a dirty part. General parts handling moves or inspects loose pieces. Reassembly returns completed components to the device. A movable part is not necessarily in the cleaning interaction.

Before scrubbing, verify three conditions: the dirty component is selected, the cleaning area has accepted it, and the cleaning interaction has opened. If one is missing, back out and repeat the placement instead of assuming the dirt texture is broken.

Prompts can vary with game version, control method, and interface state. Follow the prompt in your copy. This guide does not invent a keyboard key, mouse button, controller button, or permanent label. The stable sequence is select, engage the cleaning area, then scrub.

## Why Dirt Is Not Disappearing

These checks move from local interaction problems to session recovery. They are safe steps, not diagnoses; separate player reports do not demonstrate one shared technical cause.

### The part is near the station but not engaged

A component can sit beside the cup without entering the interaction. Pick it up, move it into the upper-right cleaning area, and wait for the interface to change. If it remains in ordinary bench handling, reposition it.

### The wrong object is selected

The complete device, a cover, or another piece may be selected while the dirty component is not. Compare the selected piece with the visible dirt and repair objective. Clear overlaps if needed, then place only the dirty component in the cleaning area.

### The input is not registering correctly

If visual progress does not respond, release the input and retry the on-screen scrubbing action. Avoid guessing a key from an older post. Check whether pointer movement works normally, and disconnect conflicting devices only as a safe, reversible test.

Audio can start even when dirt does not change, according to the cited player thread. Therefore, use visual progress as the deciding signal. Sound confirms that some feedback played; it does not by itself confirm that the component is being cleaned.

### The current session may be stuck

Exit the cleaning interaction, return to normal workbench handling, and re-enter it. If the same correctly selected component still shows no response, reload the current session or restart the game. Preserve your save through normal in-game options. Reinstallation is a later measure: one player reported that reinstalling did not resolve their issue, so it should not be the first response.

After restarting, repeat the smallest clean sequence. If it still fails, record the game version, input method, device, and component for a useful bug report.

## Cleaning Troubleshooting Checklist

1. Confirm that the current repair objective and visible surface indicate that this component needs cleaning.
2. Disassemble enough of the device to expose and select the actual dirty component, not the complete device or a clean neighbor.
3. Move the dirty component into the cup or cleaning area on the upper-right of the workbench, using that player-supplied location as a clue.
4. Wait for the cleaning interaction or its visible prompt to open before starting the scrubbing action.
5. Watch for visual dirt or progress changes instead of using cleaning sound alone as proof of progress.
6. Exit the cleaning interaction, reposition the same component, and enter the interaction again.
7. If progress still does not appear, reload the current session and then restart the game using normal save-safe steps.
8. If the issue continues, report the game version, input method, Pokia component, and the exact point where visual progress stops.

Run the list in order so each attempt changes one likely condition. This helps isolate selection, station, input, or session state and produces a clearer report.
